# Generative_AI_Research_50149986

This repository contains research data and files for the Generative AI research project.

## Project Structure

- 01_Literature_Review: journal articles, books and other research sources.
- 02_Quantitative_Analysis: survey data, survey questions, analysis files and data visualisations.
- 03_Qualitative_Analysis: interview transcripts, interview protocols, consent forms and analysis reports.
- 04_Drafts_and_Reports: research proposals, paper drafts and final reports.
- 05_Additional_Materials: information sheets, photos and other media files.

## How to Navigate the Files

Choose the folder based on the type of research material you need. Each main folder contains smaller folders for different file types.

## Collaboration Guidelines

Use clear file names and commit messages. Make changes in the correct folder. Check your changes before committing them. Collaborators should keep the project structure organised.
